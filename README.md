# Fami

Private family app for Mahdiar, Masoumeh, Mohammad, and Pendar.

## Product direction
- iOS-first visual language with restrained light/dark themes
- Home, Chat, Family, Wallet, and More
- Single + composer for Photo, Voice, Poll, Event, Announcement, Note, Expense, and Task
- Family profiles and consent-based location sharing
- Bank Muscat balance view (read-only integration later)
- OMR → USD → toman conversion and TGJU exchange-rate view
- Subscription/domain tracking
- Shared events, announcements, memories, and files

The first implementation is a Flutter prototype so we can produce an Android APK while keeping the interface intentionally iOS-like. Native integrations and backend services will be added after the visual system is locked.
